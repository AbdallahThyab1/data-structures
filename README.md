## 📌 Overview

This project implements core data structures from scratch using C++. Each structure is built with proper encapsulation, dynamic memory management, and standard operations like insert, delete, search, and traversal.

---

## ✨ Implemented Data Structures

- 📦 **Array** - Static array with basic operations
- 📋 **ArrayList** - Dynamic array with automatic resizing
- 🔗 **Singly LinkedList** - Linear collection with nodes pointing forward
- 🔄 **Doubly LinkedList** - Bidirectional node traversal
- 🥞 **Stack** - LIFO structure (array & linked list based)
- 🚶 **Queue** - FIFO structure (array & linked list based)

## 📊 Complexity Analysis

| Data Structure | Access | Search | Insertion | Deletion |
|----------------|--------|--------|-----------|----------|
| Array          | O(1)   | O(n)   | O(n)      | O(n)     |
| ArrayList      | O(1)   | O(n)   | O(n)      | O(n)     |
| LinkedList     | O(n)   | O(n)   | O(1)*     | O(1)*    |
| Doubly LinkedList | O(n) | O(n) | O(1)* | O(1)* |
| Stack          | O(n)   | O(n)   | O(1)      | O(1)     |
| Queue          | O(n)   | O(n)   | O(1)      | O(1)     |

*at known position / beginning
